# 💻 Trabajo Práctico - Sistema Bancario en Java

## 📖 Descripción

Este proyecto consiste en el desarrollo de un sistema bancario en Java, aplicando los principios de la Programación Orientada a Objetos (POO).

Permite gestionar distintos tipos de cuentas y realizar operaciones financieras básicas.

---

## 🧩 Funcionalidades

* Creación de clientes
* Gestión de cuentas bancarias:

  * Caja de ahorro
  * Cuenta corriente
  * Cuenta en dólares
* Depósitos y extracciones
* Giro en descubierto
* Conversión de moneda (dólar a pesos)
* Manejo de cheques

---

## 🛠️ Tecnologías utilizadas

* Java
* Spring Boot
* Lombok
* Maven

---

## 📂 Estructura del proyecto

* `entidades.clientes`
* `entidades.cuentas`
* `tests`

---

## 🚀 Cómo ejecutar el proyecto

1. Clonar el repositorio
2. Abrirlo en un IDE (Eclipse, IntelliJ, VS Code)
3. Ejecutar las clases de prueba (tests)
